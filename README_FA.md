# Toner Saver PDF

ابزار آفلاین ویندوز برای تبدیل اسلایدهای PDF با پس‌زمینه تیره به نسخه مناسب چاپ سیاه‌وسفید.

## چه کاری انجام می‌دهد؟

- PDF مستقیماً باز و رندر می‌شود؛ به PowerPoint تبدیل نمی‌شود.
- شکل و چینش متن فارسی و انگلیسی تغییر نمی‌کند.
- فقط صفحه‌هایی که پس‌زمینه تیره دارند پردازش می‌شوند.
- صفحه‌های روشن بدون افت کیفیت و به‌صورت وکتور به خروجی منتقل می‌شوند.
- عکس‌های داخل اسلاید در حالت پیش‌فرض به شکل خاکستری حفظ می‌شوند.
- دو خروجی دارد:
  - **متعادل:** خاکستری با جزئیات بیشتر.
  - **اقتصادی:** متن و اشکال سیاه‌وسفید خالص و کم‌مصرف‌تر.

> نکته: صفحه‌های اصلاح‌شده به تصویر با کیفیت 300 DPI تبدیل می‌شوند. برای چاپ معمولی و جزوه مناسب است، ولی متن این صفحه‌ها دیگر قابل انتخاب نیست.

## نصب آسان در ویندوز

1. Python 3.11 یا جدیدتر را نصب کنید و هنگام نصب گزینه `Add Python to PATH` را فعال کنید.
2. روی `install.bat` دوبار کلیک کنید.
3. بعد از پایان نصب، روی `run.bat` دوبار کلیک کنید.

## ساخت فایل EXE مستقل

روی `build_exe.bat` دوبار کلیک کنید. خروجی در این مسیر ساخته می‌شود:

```text
dist\TonerSaverPDF.exe
```

## تنظیمات پیشنهادی برای کار روزانه

- کیفیت: `300 DPI`
- حالت: ابتدا `متعادل`، برای جزوه‌های متنی ساده `اقتصادی`
- حد تیرگی: `125`
- حداقل پوشش: `42%`
- حفظ عکس‌ها: روشن
- اجبار پردازش همه صفحات: خاموش

قبل از چاپ تعداد بالا، یک برگ آزمایشی چاپ کنید.

## اجرای خط فرمان

```bat
.venv\Scripts\python.exe cli.py file.pdf -o output --dpi 300 --mode balanced
```

حالت اقتصادی:

```bat
.venv\Scripts\python.exe cli.py file.pdf -o output --mode economy
```

## محدودیت‌ها

- بهترین نتیجه برای PDFهایی است که مستقیماً از PowerPoint خروجی گرفته شده‌اند.
- صفحه‌های دارای گرادیان بسیار پیچیده یا عکس تمام‌صفحه ممکن است نیاز به تنظیم «حد تیرگی» داشته باشند.
- در حالت حفظ عکس، عکس‌های بزرگ‌تر از 48٪ صفحه به‌عنوان اسلاید تخت‌شده تلقی و همراه کل صفحه پردازش می‌شوند.

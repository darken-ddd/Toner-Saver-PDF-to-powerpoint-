# Toner Saver PDF

ابزار آفلاین ویندوز برای آماده‌سازی فایل‌های PDF، مخصوصاً PDFهایی که مستقیماً از **PowerPoint** خروجی گرفته شده‌اند، برای چاپ سیاه‌وسفید کم‌مصرف‌تر.

هدف اصلی پروژه این است که اسلایدهایی با پس‌زمینه‌های تیره، مشکی یا سرمه‌ای را بدون نیاز به تبدیل PDF به PowerPoint، برای چاپ روی پرینترهای سیاه‌وسفید آماده کند؛ در نتیجه مشکل به‌هم‌ریختن متن‌های فارسی و انگلیسی هنگام تبدیل PDF به PPT تا حد زیادی حذف می‌شود.

> ⚠️ این پروژه یک ابزار پردازش تصویر برای چاپ است، نه یک ویرایشگر PDF. برای صفحه‌هایی که پردازش می‌شوند، محتوای صفحه به تصویر خاکستری تبدیل می‌شود؛ بنابراین متن آن صفحه‌ها بعد از پردازش دیگر قابل انتخاب یا جست‌وجو نخواهد بود.

---

## ✨ قابلیت‌ها

- تشخیص خودکار صفحه‌هایی که پس‌زمینه تیره دارند.
- تبدیل پس‌زمینه‌های تیره به زمینه روشن برای کاهش مصرف تونر.
- حفظ محتوای بصری متن‌های فارسی و انگلیسی بدون تبدیل PDF به PowerPoint.
- پردازش فقط صفحه‌های تیره و انتقال مستقیم صفحه‌های روشن به خروجی.
- پشتیبانی از پردازش چند فایل PDF در یک اجرا.
- پیش‌نمایش **قبل / بعد** برای بررسی نتیجه پردازش.
- دو حالت پردازش:
  - **متعادل (`balanced`)**: حفظ جزئیات بیشتر و مناسب جزوه‌ها و اسلایدهای دارای نمودار.
  - **اقتصادی (`economy`)**: تبدیل شدیدتر به سیاه‌وسفید برای کاهش بیشتر مصرف تونر.
- امکان حفظ عکس‌های داخل اسلاید به صورت خاکستری.
- امکان پردازش اجباری همه صفحه‌ها در صورت نیاز.
- انتخاب کیفیت پردازش در `200`، `300` یا `400 DPI`.
- رابط گرافیکی ساده با Tkinter.
- ابزار خط فرمان (CLI) برای استفاده در اسکریپت‌ها و پردازش دسته‌ای.
- امکان ساخت فایل مستقل `.exe` با PyInstaller.
- کاملاً آفلاین؛ فایل‌های PDF برای پردازش به سرویس آنلاین ارسال نمی‌شوند.

## 🎯 مناسب برای چه کاری است؟

این پروژه برای شرایطی طراحی شده است که یک فایل PowerPoint ابتدا به PDF تبدیل شده و سپس برای چاپ سیاه‌وسفید ارسال می‌شود.

نمونه رایج:

```text
PowerPoint
    ↓
Export / Save as PDF
    ↓
PDF با پس‌زمینه تیره
    ↓
Toner Saver PDF
    ↓
PDF مناسب‌تر برای چاپ سیاه‌وسفید
```

به‌خصوص برای:

- چاپخانه‌ها و مراکز زیراکس
- چاپ جزوه‌های دانشگاهی
- چاپ اسلایدهای ارائه
- فایل‌های آموزشی با تم تیره
- فایل‌هایی که تبدیل PDF → PowerPoint در آن‌ها باعث به‌هم‌ریختن متن فارسی می‌شود

## 🖼️ استفاده از رابط گرافیکی

پس از اجرای `run.bat`:

1. روی **افزودن PDF** کلیک کنید.
2. یک یا چند فایل PDF را انتخاب کنید.
3. تنظیمات پردازش را انتخاب کنید.
4. در صورت نیاز روی **پیش‌نمایش** کلیک کنید تا نتیجه یک صفحه بررسی شود.
5. پوشه خروجی را انتخاب کنید.
6. روی **شروع پردازش** کلیک کنید.

فایل‌های خروجی با نامی مشابه زیر ذخیره می‌شوند:

```text
lecture.pdf
lecture_TonerSaver.pdf
```

صفحه‌هایی که پس‌زمینه روشن دارند، در حالت عادی بدون پردازش سنگین به خروجی منتقل می‌شوند و صفحه‌های تشخیص‌داده‌شده به عنوان صفحه تیره، برای چاپ بازطراحی می‌شوند.

## ⚙️ تنظیمات

### کیفیت (`DPI`)

| مقدار | کاربرد پیشنهادی |
|---|---|
| `200` | پردازش سریع‌تر و فایل کوچک‌تر |
| `300` | پیشنهاد عمومی برای چاپ جزوه |
| `400` | جزئیات بیشتر در خروجی پردازش‌شده |

### حالت خروجی

#### متعادل (`balanced`)

برای زمانی که خوانایی و جزئیات مهم‌تر از کمترین مصرف تونر است.

- حفظ بهتر طیف خاکستری
- مناسب متن، نمودار و عناصر گرافیکی
- انتخاب مناسب برای اکثر فایل‌ها

#### اقتصادی (`economy`)

برای زمانی که هدف اصلی کاهش مصرف تونر است.

- خروجی بسیار نزدیک به سیاه‌وسفید خالص
- مصرف تونر کمتر
- ممکن است جزئیات ظریف یا طیف‌های خاکستری حذف شوند

### حد تیرگی پس‌زمینه

این پارامتر مشخص می‌کند چه مقدار روشنایی برای تشخیص یک صفحه به عنوان صفحه تیره در نظر گرفته شود.

مقدار پیش‌فرض:

```text
125
```

اگر فایل شما دارای پس‌زمینه خاکستری یا رنگی است و ابزار آن را تشخیص نمی‌دهد، می‌توانید این مقدار را تنظیم کنید.

### حداقل پوشش پس‌زمینه

مشخص می‌کند چه مقدار از صفحه باید با رنگ پس‌زمینه مشابه پوشیده شده باشد تا صفحه به عنوان اسلاید تیره تشخیص داده شود.

مقدار پیش‌فرض:

```text
42%
```

### حفظ عکس‌ها

با فعال بودن این گزینه، عکس‌های تعبیه‌شده داخل اسلاید تلاش می‌شود به صورت خاکستری معمولی حفظ شوند تا جزئیات تصویر بهتر بماند.

### اجبار پردازش همه صفحه‌ها

در حالت عادی فقط صفحه‌های تشخیص‌داده‌شده به عنوان تیره پردازش می‌شوند.

با فعال کردن این گزینه، همه صفحه‌های PDF پردازش می‌شوند.

## ⌨️ استفاده از CLI

### پردازش یک فایل

```bat
.venv\Scripts\python.exe cli.py lecture.pdf
```

### مشخص کردن پوشه خروجی

```bat
.venv\Scripts\python.exe cli.py lecture.pdf -o output
```

### انتخاب کیفیت

```bat
.venv\Scripts\python.exe cli.py lecture.pdf --dpi 300
```

### حالت اقتصادی

```bat
.venv\Scripts\python.exe cli.py lecture.pdf --mode economy
```

### تغییر آستانه تشخیص تیرگی

```bat
.venv\Scripts\python.exe cli.py lecture.pdf --dark-threshold 125
```

### تغییر حداقل پوشش پس‌زمینه

```bat
.venv\Scripts\python.exe cli.py lecture.pdf --coverage 0.42
```

### غیرفعال کردن حفظ عکس‌ها

```bat
.venv\Scripts\python.exe cli.py lecture.pdf --no-preserve-images
```

### پردازش اجباری همه صفحه‌ها

```bat
.venv\Scripts\python.exe cli.py lecture.pdf --force-all
```

### پردازش چند فایل در یک اجرا

```bat
.venv\Scripts\python.exe cli.py file1.pdf file2.pdf file3.pdf -o output
```

## 🧠 نحوه کار فنی

پردازش پروژه بر پایه رندر کردن صفحات PDF و تحلیل آماری رنگ‌ها انجام می‌شود.

روند کلی:

```text
PDF
 │
 ├─ Render page
 │
 ├─ Detect dominant background color
 │
 ├─ Analyze border / page coverage
 │
 ├─ Detect dark background
 │
 ├─ Detect embedded image regions
 │
 ├─ Convert dark slide to grayscale print version
 │
 └─ Save optimized PDF
```

برای تشخیص پس‌زمینه، رنگ غالب نواحی حاشیه و نمونه‌برداری از کل صفحه بررسی می‌شود. این روش کمک می‌کند اسلایدهایی با پس‌زمینه‌های مشکی، سرمه‌ای و رنگ‌های تیره تشخیص داده شوند.

در صفحه‌های تیره، تبدیل تصویر بر اساس اختلاف روشنایی با رنگ غالب پس‌زمینه انجام می‌شود تا پس‌زمینه به سفید نزدیک شود و عناصر اصلی اسلاید در خروجی چاپ باقی بمانند.

عکس‌های تعبیه‌شده نیز در صورت فعال بودن گزینه حفظ عکس‌ها با یک ماسک جداگانه شناسایی می‌شوند تا به صورت خاکستری طبیعی‌تر حفظ شوند.

## 📌 نکته مهم درباره کیفیت و ساختار PDF

این پروژه دو نوع صفحه در خروجی دارد:

### صفحه‌های پردازش‌نشده

صفحه‌هایی که تیره تشخیص داده نمی‌شوند، مستقیماً از PDF اصلی به خروجی منتقل می‌شوند. بنابراین ساختار وکتوری آن‌ها تا حد زیادی حفظ می‌شود.

### صفحه‌های پردازش‌شده

صفحه‌های تیره برای کاهش مصرف تونر به تصویر خاکستری تبدیل می‌شوند و سپس داخل PDF جدید قرار می‌گیرند.

در نتیجه:

- ظاهر بصری متن فارسی و انگلیسی حفظ می‌شود.
- مشکل RTL و به‌هم‌ریختگی متن ناشی از PDF → PPT ایجاد نمی‌شود.
- متن صفحه پردازش‌شده قابل انتخاب یا جست‌وجو نیست.
- کیفیت صفحه به DPI انتخاب‌شده وابسته است.
- خروجی فشرده‌سازی JPEG دارد و برای آرشیو حرفه‌ای یا چاپ با کیفیت بسیار بالا بهتر است قبل از استفاده گسترده، نمونه چاپی بررسی شود.

## ✅ تنظیمات پیشنهادی برای چاپ جزوه

برای استفاده روزمره در مرکز چاپ یا زیراکس، پیشنهاد اولیه:

```text
DPI: 300
Mode: Balanced
Dark threshold: 125
Minimum background coverage: 42%
Preserve images: Enabled
Force all pages: Disabled
```

برای فایل‌هایی که تقریباً فقط متن و شکل دارند و هدف اصلی کاهش مصرف تونر است:

```text
DPI: 300
Mode: Economy
Preserve images: Disabled یا بر اساس نیاز
```

قبل از چاپ تعداد زیاد، یک یا دو صفحه را آزمایشی چاپ کنید.

## ⚠️ محدودیت‌ها

- بهترین عملکرد برای فایل‌هایی است که از PowerPoint یا نرم‌افزارهای مشابه به PDF خروجی گرفته شده‌اند.
- تشخیص صفحه تیره مبتنی بر تحلیل تصویر است و در فایل‌های پیچیده ممکن است نیاز به تنظیم آستانه‌ها داشته باشد.
- صفحه‌هایی که عکس تمام‌صفحه یا اسکرین‌شات تمام‌صفحه دارند ممکن است مانند یک اسلاید تخت‌شده پردازش شوند.

- PDFهای رمزگذاری‌شده یا دارای رمز عبور قابل پردازش نیستند مگر اینکه ابتدا قفل آن‌ها برداشته شود.
- صفحه‌های پردازش‌شده به صورت تصویر در PDF خروجی ذخیره می‌شوند و قابلیت انتخاب متن را از دست می‌دهند.

## 🛠️ توسعه‌دهندگان

نصب وابستگی‌ها به صورت دستی:

```bat
py -3 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

اجرای برنامه:

```bat
python app.py
```

اجرای CLI:

```bat
python cli.py sample\demo_dark_slides.pdf
```

ساخت EXE:

```bat
pip install -r requirements-build.txt
pyinstaller --noconfirm --clean --onefile --windowed ^
  --name "TonerSaverPDF" ^
  --collect-all pymupdf ^
  app.py
```
